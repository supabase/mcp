Skills & Agent Roles — مهارات ووظائف الوُكلاء

English (brief)
- Orchestrator: coordinates rounds, dispatches to HeadNodes, aggregates outputs.
- HeadNode: host for 5 subagents (2 QuestionDrafters, 2 FactLinkers, 1 ContradictionDetector).
- QuestionDrafter: formulates clarification/follow-up questions.
- FactLinker: maps facts to legal references (articles, clauses, precedents).
- ContradictionDetector: signals diversity/inconsistency in linked references.
- JudgePanel: evaluates aggregated outputs, classifies contradictions, and issues next-step directives.

عربي (مختصر)
- المنسق: يوزع ويجمع ويُدير جولات السؤال/الرد.
- رأس (HeadNode): يحتوي 5 وكلاء فرعيين (2 صياغة أسئلة، 2 ربط وقائع، 1 رصد تناقضات).
- صياغة الأسئلة: تولد أسئلة توضيحية ومتابعة.
- رابط الوقائع: يطابق الوقائع بالمواد/المواد القانونية.
- مكتشف التناقض: يعلّم عن تباينات المراجع بين الرؤوس.
- هيئة القضاة: تجمع المخرجات وتقرر قبول/طلب توضيح/دمج.

Usage: This file documents the logical skills implemented in the prototype and serves as a reference for reviewers and developers.
